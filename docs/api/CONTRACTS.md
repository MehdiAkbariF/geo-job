## ۱. جستجوی دیدگاه نقشه (Viewport Search)
کلاینت با هر بار جابجایی نقشه یا کلیک روی "جستجو در این محدوده"، این اندپوینت را صدا می‌زند.

- **مسیر:** `GET /api/v1/map/features`
- **پارامترها:**
  - `bbox`: `west,south,east,north` (اجباری)
  - `zoom`: سطح زوم نقشه بین 0 تا 22 (اختیاری، پیش‌فرض 12)
  - `limit`: سقف نتایج (حداکثر 1000، پیش‌فرض 200)

### رفتار هوشمند نسبت به زوم (Zoom-aware):
- در زوم‌های پایین (`zoom < 11`): سرور به صورت خودکار خوشه‌ها (`Clusters`) را برمی‌گرداند تا رندر موبایل با افت فریم مواجه نشود.
- در زوم‌های بالا (`zoom >= 11`): سرور نقاط منفرد استاندارد GeoJSON را ارسال می‌کند.

**نمونه فراخوانی:**
```text
GET /api/v1/map/features?bbox=51.2,35.6,51.9,35.8&zoom=14
۲. جستجوی شعاعی اطراف کاربر (Nearby Search)
یافتن نزدیک‌ترین نقاط به موقعیت مکانی جاری کاربر با مسافت واقعی بر حسب متر.
مسیر: GET /api/v1/map/nearby
پارامترها:
lat: عرض جغرافیایی نقطه مرکز
lon: طول جغرافیایی نقطه مرکز
radius: شعاع به متر (مثلاً 5000 برای ۵ کیلومتر)
limit: تعداد نتایج (حداکثر 500)
نمونه فراخوانی:

Text
GET /api/v1/map/nearby?lat=35.7006&lon=51.3381&radius=5000
۳. دریافت تایل وکتور داینامیک (Vector Tiles / MVT)
برای کتابخانه‌های نقشه موبایل مانند MapLibre GL یا Mapbox SDK.
مسیر: GET /api/v1/tiles/{z}/{x}/{y}.mvt
فرمت خروجی: application/x-protobuf (بایت‌های فشرده MVT استاندارد Mapbox)

پارامترها:
